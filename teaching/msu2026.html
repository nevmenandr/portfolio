Способ посчитать хи-квадрат (χ²) в R

Пример: 30, 10, 15, 45.

  yes no
A 30 10
B 15 45

Расшифровка:

  • 30 — сколько объектов с признаком A имеют результат yes
  • 10 — сколько объектов с признаком A имеют результат no
  • 15 — сколько объектов с признаком B имеют результат yes
  • 45 — сколько объектов с признаком B имеют результат no

Допустим, вы опросили 100 человек: 40 из группы A и 60 из группы B, и спросили «согласны?» (yes/no):

  • Из 40 человек группы A: 30 сказали «yes», 10 — «no» → строка A: 30, 10
  • Из 60 человек группы B: 15 сказали «yes», 45 — «no» → строка B: 15, 45

Не должно быть < 5

Сумма всех четырёх чисел = общее число наблюдений n = 30 + 10 + 15 + 45 = 100. Это n и подставляется в формулу V Крамера.

Числа идут по строкам (при byrow = TRUE): сначала вся первая строка (30, 10), потом вторая (15, 45).

my_table <- matrix(c(30, 10,   # строка A: yes=30, no=10
                     15, 45),  # строка B: yes=15, no=45
                   nrow = 2, byrow = TRUE)

Если перепутать порядок и ввести по столбцам, таблица «перевернётся» — χ² и V Крамера посчитаются, но уже для другой раскладки. Поэтому byrow = TRUE важен.

# --- 1. Вводим готовые частоты (по строкам!) ---
my_table <- matrix(c(30, 10,
                     15, 45),
                   nrow = 2, byrow = TRUE)
my_table

# --- 2. Хи-квадрат ---
test <- chisq.test(my_table)
test

# --- 3. V Крамера (для 2×2 он же Phi) ---
cramers_v <- sqrt(test$statistic / sum(my_table))
cramers_v

Примерный вывод:

Pearson's Chi-squared test with Yates' continuity correction

data:  my_table
X-squared = 18.75, df = 1, p-value = 1.485e-05

V Крамера = 0.5

Значение V Крамера находится в диапазоне от 0 до 1:

0 — связи нет.

1 — максимально возможная связь (для данной размерности таблицы).

Чем ближе к 1, тем сильнее связь. Обычно значения около 0.1 считаются слабыми, 0.3 — средними, 0.5 и выше — сильными, но это зависит от контекста.

Интерпретация:

  • p-value = 1.485e-05 (≈ 0.000015) — меньше 0.05 → связь между переменными статистически значима, гипотеза о независимости отвергается.
  • V Крамера = 0.5 — величина эффекта; 0.5 для таблицы 2×2 означает сильную связь (ориентиры: 0.1 — слабая, 0.3 — средняя, 0.5+ — сильная).
  • X-squared = 18.75, df = 1 — промежуточные цифры теста; сами по себе для интерпретации не нужны, важны через p-value.

Итог: связь есть, она значима (p < 0.001) и сильная (V = 0.5).

Язык запросов Google Books Ngram Viewer

  • Поиск по n-граммам: Запрос может содержать до 7 слов. Пример.
  • Подстановочные знаки (Wildcards): Символ * заменяет одно слово и показывает топ-10 самых частых вариантов. Например, University of *.
  • Поиск по словоформам (Inflection search): Добавление _INF к слову находит все его грамматические формы. Например, book_INF найдёт book, books, booked, booking.
  • Поиск без учёта регистра: Позволяет суммировать все варианты написания слова с разным регистром (например, DuPont, Dupont, DUPONT).
  • Части речи (Part-of-speech tags): Можно указать часть речи, добавив тег через подчёркивание, например book_VERB или choice_NOUN.
  • Операторы для комбинирования запросов:
    • + (сложение): Суммирует частотность нескольких n-грамм: пример.
    • * (умножение): Масштабирует график для сравнения редких и частых слов (требует скобок): пример.

Работа со stylo

  1. Устанвить R.
  2. В командной строке выполнить установку stylo (требуется только при первом запуске): install.packages ("stylo")
  3. Подгрузить библиотеку stylo: library (stylo)
  4. Попробовать запустить графический интерфейс stylo, вызвав функцию stylo() (нажать Enter)
    • Если вы используете MacOS и на экране появилась ошибка с упоминанием XQuartz, вам потребуется установить XQuartz
  5. Должно появиться такое окно:
  1. Создайте на компьютере папку, которая называется corpus (это важно, называться она должна именно так).
  2. Укажите stylo, где находится папка с вашим корпусом: setwd("путь/к/папке"), путь должен указывать на папку, в которой находится corpus, а не на саму corpus. Например: setwd("RSD-main/author/fiction/period/19-1").
  3. В открывшемся меню в первой вкладке (Input & language) ставим язык Other.
  4. Если не трогать остальные настройки, то после нажатия «OK» тексты из папки corpus кластеризуются по своей стилеметрической близости.
